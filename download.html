当前版本

加班计算器是一个 macOS 桌面工具，用于读取考勤记录并按预设规则估算当月加班时长。它适合需要每月核对打卡、统计调休或快速复盘工时的人使用。

安装和使用

  1. 打开上方 GitHub Releases 下载页面。
  2. 下载适合 macOS 的应用文件。
  3. 首次打开时，如果系统提示来自互联网应用，请按 macOS 的安全提示确认来源。
  4. 输入考勤系统账号和密码，点击获取考勤。
  5. 查看每日加班时长和当月汇总，并按公司制度自行核对。

建议只从本站或 GitHub Releases 下载，避免使用他人转发的安装包。

数据和隐私

工具运行在你的本地电脑上，账号密码不会上传到 Ned's Tools 的服务器。本站是静态网站，不提供后台账号系统，也不保存你的考勤数据。
