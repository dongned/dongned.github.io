关于 Dong's Tools

我是谁

你好！我是一名制造业工程师，日常工作需要处理大量的考勤和加班数据。我发现手动计算加班时长既繁琐又容易出错，于是开始自己写工具来解决这个问题。

我不是专业程序员，编程对我来说是解决实际问题的手段。每当我遇到重复性工作，就会想办法用代码把它自动化。

为什么做这些工具

最初只是给自己用的。后来发现身边的同事也有同样的需求——每月算加班很头疼，公司系统只显示打卡时间，不直接告诉你加班了多少小时。

于是我把工具分享出去，反馈还不错，就决定持续维护和更新。如果你也有类似的需求，欢迎使用。

工具开发原则

  • 简单实用 — 不搞花哨的功能，只解决核心问题
  • 数据安全 — 你的数据只保存在你自己的电脑上，绝不传到第三方
  • 免费开放 — 所有工具完全免费，没有任何隐藏收费
  • 持续更新 — 根据实际使用反馈不断改进

技术栈

工具主要使用 Python + PyQt6 开发，通过 PyInstaller 打包成 macOS 应用。网站使用纯静态 HTML + CSS，托管在 GitHub Pages 上。
