GitHub

问题反馈：kaoqing Issues

适合反馈的内容

  • 下载链接失效、安装失败或打开异常。
  • 加班计算结果和你所在公司的制度不一致。
  • 某些考勤记录无法识别或跨天规则不符合预期。
  • 网站说明有错误、过期或不够清楚。
  • 希望后续支持 Windows 或其他功能。

处理方式

本站和工具是个人维护项目，我会优先处理影响下载、安装、核心计算逻辑和隐私说明的问题。涉及具体公司制度的差异，会先补充说明，再评估是否需要做成可配置规则。
